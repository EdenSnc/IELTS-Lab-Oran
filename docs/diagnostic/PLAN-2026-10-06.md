# Separate diagnostic implementation plan

> Agentic workers: use superpowers:subagent-driven-development. Each assigned
> implementer works without spawning further agents. User selected GPT-6.1 Sol.

Goal: staff-invited free 60-minute diagnostic plus separate 7-minute in-person
Speaking, optional post-session AI, human-approved report; old mock untouched.

Architecture: separate diagnostic modules/routes and server state machine. Reuse
published source content, core assembly/scoring primitives and existing domain
tables where contracts permit; do not extend old mock services to accept diagnostics.

Tech: existing Next App Router, TypeScript, Prisma 7/app_private, Supabase SSR,
QStash, Node test runner/tsx. No dependency upgrades.

Spec: `docs/diagnostic/DESIGN-2026-10-06.md` (approved 2026-10-06).

## Global constraints

- Work only in IELTS-Lab-Oran-diagnostic, branch codex/short-diagnostic.
- Old mock routes, runner, timing, grading, entitlements and content unchanged.
- Reuse read-only primitives; keep diagnostic validation out of ordinary parsers.
- Free staff invitations, account bound, one attempt, seven days to start.
- Written 1200/1200/1200 seconds; Speaking 120/60/90/150 seconds separately.
- No invented production questions, no fake band conversion, no official score.
- Server identity/ownership/deadlines; staff plus AAL2 for privileged endpoints.
- No production DB writes, charges, provider changes, push/merge/deploy in tasks.
- Recording optional; human-only alternative; no minor recordings until guardian
  flow established; audio/transcript retention 30 days, approved feedback 90 days.
- Raw body QStash verification, IDs-only messages, database durability/idempotency.
- Append-only migrations under supabase/migrations; never reset remote database.
- Preserve all unrelated changes. Stage exact task files only; docs are ignored
  by the repository's *.md pattern and require explicit force-add if committed.
- Baseline a1417c9d4a631476b472240ebea7aa65fb87f251; current WIP belongs to this task.

## Review focus

1. Cross-path access: diagnostic IDs must not unlock paid mock endpoints.
2. State at deadline: pending autosave cannot resurrect an expired section.
3. Delayed analysis must not overwrite examiner edits or resurrect deleted consent data.
4. Listening media correctness: audio identity and segment order are stronger than duration alone.
5. Real Safari/Android interruptions differ from viewport emulation; report untested hardware honestly.
